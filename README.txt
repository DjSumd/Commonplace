Commonplace: standalone app

Upload all six files together to any static web host (for example Netlify Drop at app.netlify.com/drop,
GitHub Pages or Cloudflare Pages). Open the link on a phone and choose "Add to Home Screen" to install it.
It works offline after the first visit. Each person's library, reflections and progress are stored privately
in their own browser; use Library > Keep a copy to back up or move them to another device.
